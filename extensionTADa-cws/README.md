# TADa for YouTube

Extension Chrome (Manifest V3) chặn quảng cáo YouTube + bộ tiện ích: Tải Video MP4 (1080p/720p/360p) & Nhạc MP3 (Downloader), Đánh dấu mốc thời gian & Ghi chú (Bookmarks), Lặp đoạn A-B (A-B Looper), PiP 1 chạm, Chụp ảnh màn hình (Screenshot), Tốc độ vi chỉnh 0.1x - 4.0x, tăng âm lượng 500%, Ambient Light, ẩn Shorts, ẩn thẻ kết thúc, lưới 4 cột, lọc gợi ý sidebar, cố định bình luận.

**v2.0.0 — Rebrand TADa:** giao diện theo TADa Manager (kem #FDF6EC, hổ phách #E8930C, chữ nâu #2D1F16). Logo YouTube TADa hiển thị cố định ở thanh điều hướng trên cùng YouTube, thiết kế sắc nét, không viền masthead.

## Cài đặt
1. Giải nén zip.
2. Mở `chrome://extensions` → bật **Developer mode**.
3. **Load unpacked** → chọn thư mục `extensionTADa`.
4. Cập nhật bản mới: giải nén đè thư mục cũ → bấm **Reload** trên thẻ extension. Cài đặt cũ được giữ nguyên (storage keys không đổi).
